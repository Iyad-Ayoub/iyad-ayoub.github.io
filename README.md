# Dr. Iyad Abuhadrous — Robotics, Autonomous Systems & AI Portfolio

A React, TypeScript, and Vite portfolio prepared for GitHub Pages.

## Development

Requires Node.js 20.19 or later.

```bash
npm install
npm run dev
npm run lint
npm run build
```

## Portfolio scope

Content is maintained in `src/data/` and should only use verified professional information.

Included in this version:

- selected publication records and verified DOI links where available;
- improved scholarly and professional SEO;
- refined research and project descriptions;
- balanced positioning for academic and industry R&amp;D audiences.

A downloadable CV PDF is explicitly not planned. Visitors who require a CV can contact Dr. Abuhadrous directly.

Future optional improvements:

- verified paper, project, and code links where available;
- selected research figures or visual assets;
- richer project evidence and results;
- additional scholarly metadata;
- an optional dedicated publications page if the list becomes too large.
