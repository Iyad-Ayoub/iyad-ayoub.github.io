# Dr. Iyad Abuhadrous — Research & R&D Portfolio

A React, TypeScript, and Vite portfolio prepared for GitHub Pages.

## Development

Requires Node.js 20.19 or later.

```bash
npm install
npm run dev
npm run lint
npm run build
```

Content is maintained in `src/data/`. Replace all visible `TODO` entries only with verified professional information. Add the real CV at `public/documents/Iyad_Abuhadrous_CV.pdf`; no placeholder PDF is included.
